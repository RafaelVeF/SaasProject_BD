# Harmonisation des popups Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harmoniser les confirmations, erreurs, formulaires et discussions avec le thème NexusFlow.

**Architecture:** Ajouter un dialogue partagé pour les confirmations et erreurs, sans réutiliser le formulaire actif. Centraliser le comportement clavier et la restauration du focus des modales existantes.

**Tech Stack:** HTML, JavaScript natif, Tailwind CSS, node:test.

**Spec:** `docs/superpowers/specs/2026-11-23-popups-design.md`

## Global Constraints

- Aucune bibliothèque supplémentaire.
- Préserver les thèmes clair et anthracite ainsi que les opérations métier.
- Actions destructrices rouges, actions primaires bleues.
- Aucun message injecté comme HTML.

## Review Focus

- Annulation et Échap ne déclenchent aucune suppression.
- Une erreur superposée conserve les données du formulaire.
- Le focus reste dans la fenêtre supérieure et revient au déclencheur.
- Un formulaire long défile sur petit écran.
- Plusieurs erreurs rapprochées ne perdent pas leurs résolutions.
